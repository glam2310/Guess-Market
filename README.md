# Guess Market

A Java-based application developed as an academic final project, simulating complex real-time trading events and financial market mechanics. Built with a focus on core Java proficiency, modular architecture, and advanced software engineering best practices.

## Overview

Guess Market is designed to demonstrate deep understanding of Object-Oriented Programming (OOP) principles, JVM optimization, and concurrent data processing. The system features a clean separation of concerns between its core trading engine and user interface components, ensuring high maintainability and clean design patterns.

## Architecture

The application is structured into distinct modules:
*   **Core Engine:** Handles trading logic, market event simulations, and concurrent transaction processing.
*   **UI Layer:** Interfaces with users to display real-time market updates and handle player interactions.
